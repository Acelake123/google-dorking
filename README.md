# 🔍 Google Dorking – OSINT & Reconnaissance with Search Operators

**Google Dorking** (also known as *Google Hacking*) is a powerful technique that uses advanced search operators to extract sensitive or hidden information from websites indexed by Google. This project is a curated collection of Google Dorks and techniques for ethical hacking, penetration testing, and open-source intelligence (OSINT).

---

## 📘 Description

Google Dorking allows researchers, security professionals, and ethical hackers to discover publicly available yet sensitive content such as:

- Login portals
- Exposed configuration files
- Forgotten backup files
- Database dumps
- Vulnerable web pages
- Open cameras and IoT endpoints

This project explores how specific search queries like `filetype:`, `inurl:`, `intitle:`, and `site:` can be used to uncover such data. It demonstrates the importance of secure web development practices and proper content indexing controls.

## 🔧 Techniques Covered

| Operator      | Purpose                               |
|---------------|----------------------------------------|
| `filetype:`   | Find files of specific types (e.g. `.log`, `.pdf`, `.sql`) |
| `inurl:`      | Search URLs with specific keywords     |
| `intitle:`    | Locate pages with certain titles       |
| `site:`       | Restrict searches to a particular domain |
| `cache:`      | View older versions of pages via Google’s cache |
